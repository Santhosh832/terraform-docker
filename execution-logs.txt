5. INITIAL APPLY ATTEMPT

---

Command:

The initial deployment attempt failed because host port 8080
was already being used by another service.

Error:

Ports are not available:
listen tcp 0.0.0.0:8080: bind:
Only one usage of each socket address...

---

6. TROUBLESHOOTING

---

Docker containers were checked using:

docker ps

The following services were already using Docker ports:

Jenkins:
8081 -> 8080

Docker-in-Docker:
2376
3001

Port 8080 was also checked using:

netstat -ano | findstr :8080

Port 8080 was already listening on the host.

Instead of stopping the existing Jenkins environment,
the Terraform configuration was changed to use port 8082.

---

7. TERRAFORM CONFIGURATION UPDATE

---

Updated port mapping:

Host port:      8082
Container port: 80

Configuration:

ports {
internal = 80
external = 8082
}

---

8. TERRAFORM PLAN AFTER FIX

---

Command:

terraform plan

Result:

Plan: 1 to add, 0 to change, 0 to destroy.

The Nginx image already existed in Terraform state, so
Terraform only needed to create the Docker container.
